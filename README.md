# News Monitoring System

## Описание

News Monitoring System — это система для мониторинга новостей из различных источников, их анализа и генерации отчетов.
Система состоит из нескольких микросервисов, работающих в связке для обеспечения эффективного сбора, обработки и
представления данных.

### 1. Микросервис сбора новостей

- Парсит веб-страницы сайта CNN.
- Сохраняет заголовки, тексты новостей и даты публикации в базу данных (PostgreSQL).
- Использует асинхронное выполнение операций для ускорения сбора данных.
- Отправляет сообщение в очередь сервисам анализа новостей и перевода.

### 2. Микросервис анализа новостей

- Получает новости из базы данных.
- Анализирует текст новостей (поиск ключевых слов, определение тональности текста с помощью TextBlob и nltk).
- Сохраняет результаты анализа в базу данных.

### 3. Микросервис перевода новостей

- Получает тексты новостей из базы данных.
- Переводит текст на другой язык (используется библиотека googletrans).
- Сохраняет переведенный текст в базу данных.

### 4. Микросервис генерации отчетов

- Получает данные о новостях и результатах анализа из базы данных.
- Генерирует отчет в формате `.docx` с информацией о новостях, ключевых словах и тональности.
- Отправляет отчет на email администратора (используется мок-функция для отправки email).

## Используемые технологии

- **FastAPI** – создание HTTP API.
- **SQLAlchemy** – работа с базой данных PostgreSQL.
- **RabbitMQ** – обмен сообщениями между микросервисами.
- **python-docx** – генерация отчетов.
- **BeautifulSoup / lxml** – парсинг новостных сайтов.
- **asyncio** – асинхронное выполнение операций
- **Nginx** – обратный прокси для маршрутизации запросов.

## Развертывание через Docker

Система использует `docker-compose` для контейнеризации микросервисов.

### 1. Запуск проекта

```sh
  git clone https://gitlab.lc.f-lab.tech/internship1/newsmonitoring
  cd newsmonitoring
  cp .env.template .env # при необходимости замените переменные окружения в вашем .env файле.
  docker-compose up --build
```

После успешного запуска API будет доступно на `http://localhost:80`.

### 2. **Доступные эндпоинты**

- **Парсинг новостей:** `GET /api/news/`
- **Генерация отчета:** `POST /api/report/` (в теле запроса укажите {"email": "ваш email"})

### 3. **Отчеты**

- Отчет будет доступен по пути: `newsmonitoring/reports/news_report.docx`

### 4. **Документация Swagger**:

- **News Parser**: `http://localhost:80/news/docs/`
- **Report Service**: `http://localhost:80/news/docs/`
